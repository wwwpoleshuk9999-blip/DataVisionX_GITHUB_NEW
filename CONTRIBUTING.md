# Contributing to DataVisionX

Version: Phoenix 0.5

---

# Development Rules

Every new feature must be modular.

Every module has one responsibility.

Shared services must be requested through Runtime Registry.

Global objects are forbidden.

---

# Coding Style

Python 3.14

PEP8

Type hints are recommended.

UTF-8 only.

---

# Git Workflow

Create a feature branch.

Develop.

Test.

Commit.

Merge.

---

# Commit Style

Examples:

Phoenix Build 001

Plugin Loader

Runtime API

Storage Service

CLI Update

---

# Testing

Every module must compile.

python -m py_compile

Every service should be tested before merge.

---

# Documentation

Small kernel.
